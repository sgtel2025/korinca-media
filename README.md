# korinca-media

Piezas **terminadas** de las redes de Korinca y de sus clientes, en un lugar con dirección pública para que Metricool las pueda tomar al programar una publicación.

Este repositorio es público. Aquí solo va lo que está listo para publicarse o para que se apruebe; nunca video original del negocio, material de clientes sin editar, placas, VIN ni datos de nadie.

## Qué hay

| Carpeta | De quién |
|---|---|
| `auto-module/` | Auto Module Programming |

Dentro de cada una, las piezas van por fecha de publicación: `2026-10-12-seguro-en-casa-reel.mp4`.

## De dónde sale cada pieza

Las reglas, el método y las pruebas están en el repositorio privado `korinca-rrss`. El video original que graba cada negocio vive en una carpeta privada de Drive, no aquí.

## Tamaño

GitHub no acepta archivos de más de 100 MB. Una pieza vertical de 30 segundos pesa entre 10 y 30 MB.
